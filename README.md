# LibreTV 便携版

一个 Windows 桌面客户端外壳，把开源项目 **LibreTV**（Next.js 版，v2.22.0）包装成「解压即用 / 一键安装」的本地观影工具。

本仓库只包含**外壳与增强层的源码**，不包含影片、不含视频文件、不存储任何内容。播放与下载的内容全部来自用户在客户端里自行配置的第三方公开采集接口。

## 功能

- **免安装**：自带 Node 运行时与 ffmpeg，解压后双击 `LibreTV.exe` 即可运行，不依赖系统环境
- **免登录**：内置会话自动登录，打开界面不再需要输入密码
- **内置源**：默认写入 39 个点播源 + 2 个直播源，可在「设置 → 源管理」中自行增删
- **服务端下载**：下载由本机服务执行（ffmpeg 拉流 → 落盘），关掉界面也会继续下，支持断点续传、失败重试与任务去重
- **服务自愈**：服务异常退出后由 30 秒看门狗自动拉起，启动失败自动重试
- **默认仅本机监听**：默认绑定 `127.0.0.1`，访问密码首次启动自动生成，不硬编码
- **地址解析**：自动把第三方给的「分享页」HTML 解析成真实 m3u8，并带上 UA / Referer，解决直接拉取失败的问题
- **托盘常驻**：打开界面 / 重启服务 / 停止服务 / 打开下载目录 / 关于 / 退出

## 目录结构

```
LibreTV/
├─ LibreTV.exe            客户端外壳（C# WinForms，自编译）
├─ config.ini             端口、下载目录配置
├─ runtime/
│  ├─ server.js           增强层：反向代理 + 下载队列 + 地址解析 + 自动登录
│  ├─ dl-client.js        注入到页面的下载入口与下载面板
│  ├─ sources.json        默认点播源
│  └─ live-sources.json   默认直播源
├─ node/                  内置 Node 运行时
├─ tools/ffmpeg/          内置 ffmpeg
└─ uninstall.exe          卸载入口（安装版）
```

## 安装 / 使用

**方式一：安装包（推荐）**

下载 `LibreTV-Setup-1.0.3.exe`，双击运行，选择安装目录，装完自动创建快捷方式。
卸载：运行安装目录下的 `uninstall.exe`，或在「设置 → 应用」中找到 `LibreTV 便携版`。

**方式二：便携版**

下载 `LibreTV-Portable-1.0.3.zip`，解压到任意位置，双击 `LibreTV.exe`。

服务默认监听 `http://127.0.0.1:8080`，端口或下载目录可在 `config.ini` 中修改。
